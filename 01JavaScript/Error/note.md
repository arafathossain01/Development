There are few types of error like:

- Reference Errors
- Type Errors
- Range Errors
- URI Errors
- Syntex Errors
- Eval Errors
- Silent Errors

### ReferenceError

Creation Phase-এ যখন কোনো ভ্যারিয়েবল বা ফাংশন মেমরি কম্পোনেন্টে (Memory Component) রেজিস্টার বা ডিক্লেয়ার করা হয় না, তখন মেমরি কম্পোনেন্ট ওই নামের কোনো অস্তিত্বই চেনে না। এরপর Execution Phase-এ এসে কোড কম্পোনেন্ট (Code Component) যখন লাইন বাই লাইন রান করার সময় মেমরি কম্পোনেন্টের কাছে গিয়ে বলে, "আমাকে এই ভ্যারিয়েবল বা ফাংশনটার ভ্যালু দাও", তখন মেমরি কম্পোনেন্ট তা দিতে পারে না। যেহেতু মেমরিতে এর কোনো রেফারেন্স বা সন্ধানই পাওয়া যায় না, ঠিক তখনই জাভাস্ক্রিপ্ট ইঞ্জিন ReferenceError দেয়।

```js
// গ্লোবাল বা লোকাল কোথাও 'b' ডিক্লেয়ার করা হয়নি
function outer() {
  console.log(b); // Throws ReferenceError: b is not defined
}
outer();
```

### TypeError

মেমরি কম্পোনেন্টের কাছে ভ্যারিয়েবল বা ডেটাটি আছে এবং তার একটা ভ্যালুও অ্যাসাইন করা আছে, কিন্তু কোড কম্পোনেন্ট তার সাথে এমন একটা আচরণ বা অপারেশন করতে চাচ্ছে যা ওই ডেটা টাইপের (Data Type) সাথে করা অসম্ভব বা বেআইনি! এখানে ভ্যারিয়েবলটি খুঁজে পাওয়া যাচ্ছে, কিন্তু তার Type (ধরণ) ভুল হওয়ার কারণে জাভাস্ক্রিপ্ট ইঞ্জিন TypeError ছুড়ে মারে।

```js
var log = undefined;
log(); // ❌ TypeError: log is not a function
```

- মেমরি কম্পোনেন্টের কাছে log ভ্যারিয়েবলটি আছে এবং তার মান undefined। কিন্তু কোড কম্পোনেন্ট তার পাশে ব্র্যাকেট () বসিয়ে তাকে ফাংশন হিসেবে রান করতে চাচ্ছে। যেহেতু undefined কোনো ফাংশন টাইপ ডেটা নয়, তাই এখানে TypeError আসবে।

```js
const greeting = "Hello";
greeting = "Hi"; // ❌ TypeError: Assignment to constant variable.
```

- মেমরি কম্পোনেন্টে greeting ডিক্লেয়ার করা আছে এবং তার ভ্যালু "Hello"। কিন্তু জাভাস্ক্রিপ্টে const টাইপের মেকানিজম হলো এর মান একবার অ্যাসাইন করার পর আর পরিবর্তন করা যায় না। কোড কম্পোনেন্ট যখন জোর করে তার মান বদলাতে যায়, ইঞ্জিন তখন টাইপের নিয়ম ভঙ্গের কারণে TypeError দেয়।

```js
log();

var log = function print() {
  console.log("Hello i am TypeError");
};
```

- Creation Phase-এ log মেমরি কম্পোনেন্টে undefined হিসেবে হোইস্টেড (Hoisted) হয়ে থাকে। কিন্তু Execution Phase-এ কোড কম্পোনেন্ট তাকে একটি ফাংশন হিসেবে কল বা এক্সিকিউট করতে চায়। যেহেতু undefined কোনো ফাংশন নয়, তাই ডেটা টাইপের এই অসঙ্গতির কারণে জাভাস্ক্রিপ্ট ইঞ্জিন TypeError দেয়।

```js
var log = function print() {
  console.log("Hello");
};

log(); // সফলভাবে রান করবে!
```

- Creation Phase (মেমরি তৈরি): হোইস্টিং-এর নিয়মে শুরুতে গ্লোবাল মেমরি কম্পোনেন্টে log ভ্যারিয়েবলটি undefined হিসেবে জমা থাকে।

- Execution Phase (কোড রান): কোড কম্পোনেন্ট যখন প্রথম লাইনে আসে, তখন অ্যাসাইনমেন্ট (=) অপারেশনের মাধ্যমে গ্লোবাল মেমরির সেই undefined মানটি আপডেট হয়ে পুরো ফাংশন বডিটি বসে যায়।

- ফাংশন কল (log()): এরপর পরবর্তী লাইনে যখন log(); কল করা হয়, ততক্ষণে মেমরিতে সেটি অলরেডি একটি রিয়েল ফাংশন হয়ে গেছে। ফলে কোড কম্পোনেন্ট মেমরি থেকে সরাসরি ফাংশনটি পেয়ে যায় এবং কোনো এরর (TypeError) ছাড়াই সফলভাবে কনসোলে "Hello" প্রিন্ট করে।

- ট্রিকি নোট: ফাংশনের ভেতরের নাম print শুধু তার লোকাল স্কোপেই কাজ করে, তাই গ্লোবাল থেকে সরাসরি print(); কল করলে ReferenceError আসবে।

### Range Error

সীমার বাইরে চলে যাওয়া। কোনো ফাংশন বা মেথডে এমন একটি মান বা আর্গুমেন্ট পাস করা যা তার অনুমোদিত সীমার (Range) বাইরে।

```js
let arr = new Array(-1); // RangeError: Invalid array length
```

---

### URI Errors

লিংকে গোলমাল। ইউআরএল বা ইউআরআই (Uniform Resource Identifier) এনকোড বা ডিকোড করার গ্লোবাল ফাংশনগুলো (decodeURI(), encodeURIComponent()) ব্যবহার করার সময় যদি ভুল/অবৈধ ক্যারেক্টার দেওয়া হয়।

```js
decodeURIComponent('%'); 
// URIError: Malformed URI sequence (কারণ % এর পর সঠিক হেক্সাডেসিমেল কোড নেই)
```

### Syntex Error / পার্সিং এরর

ব্যাকরণগত ভুল। আপনি জাভাস্ক্রিপ্ট ভাষার নিয়ম বা গ্রামার না মেনে কোড লিখলে এই এরর হয়। এটি কোড রান হওয়ার আগেই (Parsing এর সময়) ধরা পড়ে।

```js
// ব্র্যাকেট বা কোটেশন শেষ না করলে
if (true { 
  console.log("Hello");
// SyntaxError: Unexpected token '{'
```

### Silent Error

যে ভুলগুলো স্ক্রিনে আসে না, কিন্তু ব্যাকএন্ডে ক্ষতি করে। এটি জাভাস্ক্রিপ্টের কোনো অফিশিয়াল এরর অবজেক্ট নয়। এটি একটি টার্ম বা পরিস্থিতি। এর মানে হলো কোডে এমন একটা ভুল হয়েছে যার কারণে আউটপুট ভুল আসছে, কিন্তু জাভাস্ক্রিপ্ট কোনো এরর মেসেজ দেখাচ্ছে না বা কোড ক্র্যাশ করছে না।

```js
// জাভাস্ক্রিপ্টে 'undefined' এর কোনো প্রোপার্টি রিড বা রাইট করা যায় না
// কিন্তু কিছু ক্ষেত্রে ভুল করলেও কোড সাইলেন্টলি পার পেয়ে যায়:

const obj = {};
Object.defineProperty(obj, 'readOnlyProp', {
  value: 42,
  writable: false // এটি পরিবর্তন করা যাবে না
});

obj.readOnlyProp = 99; // পরিবর্তন করার চেষ্টা (ভুল)
console.log(obj.readOnlyProp); // আউটপুট: 42 (কোনো এরর দেখাবে না, সাইলেন্টলি ইগনোর করবে)
```

**প্রতিকার:** কোডের শুরুতে "use strict"; ব্যবহার করলে এই সাইলেন্ট এররগুলো সরাসরি TypeError হিসেবে স্ক্রিনে ধরা দেয়
