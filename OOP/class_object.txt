- Concept of Object Oriented Programming

1. Object Oriented is a methodology to design a program using class and object.
2. Provides a means of structuring programs so that properties and behaviors are buldled into  individual objects.
3. It makes visualization easier because it is closest to real world scenarios.
4. It simplify software development and maintenance. 

- Pillers of OOP

1. Encapsulation
2. Inheritance
3. Polymorphism
4. Abstraction

- Class কী?

Class হচ্ছে একটা blueprint (নকশা) যেখান থেকে object তৈরি করা যায়। ক্লাস একটা user-defined type (ব্যবহারকারীর নিজস্ব ডাটা টাইপ)। যখন class বানানো হয়, তখন তা memory-তে কোনো জায়গা দখল করে না। কিন্তু class থেকে যখন object বানানো হয়, ঠিক তখনই তা memory-তে জায়গা দখল করে।

Class-এর ভেতরে মূলত দুটি জিনিস থাকে:
১. বিভিন্ন ধরনের data definitions, যাদের বলা হয় Fields বা Attributes।
২. বিভিন্ন ধরনের functions, যাদের বলা হয় Methods।
Class-এর ভেতরে থাকা ডাটাগুলোকে বাইরে থেকে কীভাবে অ্যাক্সেস করা যাবে, তার জন্য কিছু নিয়ম রয়েছে, যাদের Access Modifiers বলে।

1. default : কোনো কিছু উল্লেখ না করলে এটি থাকে। শুধুমাত্র নিজের প্যাকেজের (Package) ভেতরে অ্যাক্সেস করা যায়।

2. private : সবথেকে সুরক্ষিত। শুধুমাত্র নিজের ক্লাসের ভেতর ছাড়া বাইরে কোথাও থেকে অ্যাক্সেস করা যায় না।

3. protected : নিজের প্যাকেজে এবং অন্য প্যাকেজের চাইল্ড ক্লাসে (Sub-class) অ্যাক্সেস করা যায়।

4. public : সম্পূর্ণ উন্মুক্ত। যেকোনো প্যাকেজ বা যেকোনো ক্লাস থেকে সরাসরি অ্যাক্সেস করা যায়।

- Object কী?

Object হলো ওওপি (OOP) সিস্টেমের একটি Runtime Entity। এটি মূলত কোনো Class-এর একটি বাস্তব রূপ (Instance)।

Runtime Entity: প্রোগ্রাম যখন Run করে, তখন মেমরিতে (RAM) জায়গা দখল করে একটি অবজেক্ট বাস্তবে তৈরি হয় এবং নিজের কাজ শুরু করে। রান টাইমে অবজেক্টের এই বাস্তব অস্তিত্ব বা সত্তা থাকার কারণেই অবজেক্টকে ওওপি-র ভাষায় একটি Runtime Entity বলা হয়। 
ক্লাস থেকে মেমরিতে জায়গা নিয়ে অবজেক্ট তৈরি হওয়ার এই পুরো সিস্টেম বা প্রক্রিয়াকে বলা হয় Instantiation। (যেমন Java-তে new কিওয়ার্ড ব্যবহার করে এই কাজটি করা হয়)।

একটি অবজেক্ট হলো মূলত Data (Fields) এবং Behavior (Methods)-এর একটি সমন্বিত বান্ডেল বা প্যাকেজ। এর ভেতরে থাকা ডাটাগুলো অবজেক্টের স্টেট (State) বা অবস্থা নির্দেশ করে, আর মেথডগুলো তার কাজ বা বিহেভিয়ার প্রকাশ করে।
